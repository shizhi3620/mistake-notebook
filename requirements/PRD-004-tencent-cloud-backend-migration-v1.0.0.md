# PRD-004: 腾讯云生产后端迁移

| 字段 | 内容 |
| --- | --- |
| 当前版本 | v1.0.0 |
| 创建日期 | 2026-09-03 |
| 状态 | 可开发 |
| 基线文档 | PRD-002、PRD-003、ADR-0001 |
| 变更性质 | 从已销毁的微信云托管迁移至普通腾讯云生产架构 |

## 问题陈述

家长作业讲解与错题本需要稳定地支持微信登录、图片上传、异步视觉识别、作业批改和学习闭环。原微信云托管环境已销毁，且其对象存储身份、独立云函数、私网 DNS 与异步 Worker 的边界不能满足当前架构：独立 SCF 无法继承云托管对象存储身份，云托管内部域名也不能作为 SCF 的可靠访问入口。

产品尚未上线且没有需要迁移的生产数据。团队已购买腾讯云 CVM，现有域名正在 ICP 备案审核中。需要建立一个不依赖微信云托管的完整生产后端，使小程序在备案完成后可通过受保护的 HTTPS API 使用普通腾讯云 COS、TencentDB/CynosDB MySQL、SCF、NAT、TCR 和 CLS。

## 解决方案

建立同地域的普通腾讯云生产环境。CVM 上的 Nginx 与 Docker 化 Node.js API 对外提供备案域名的 HTTPS 接口；API、SCF 与新建 MySQL 经 VPC 私网通信；小程序通过 API 获得短期、受限的 COS 上传凭证并直传图片；API 创建持久化识别任务后异步触发 SCF Worker；Worker 使用最小 CAM 权限从 COS 读取任务图片、调用 DeepSeek，并将结果写回 MySQL。小程序继续轮询任务状态并进入既有家长确认流程。

迁移以全新环境上线为目标，不迁移已销毁微信云托管环境的数据、图片、域名或配置。备案完成前只允许受控联调；备案与 HTTPS 生效后再将小程序生产 API 地址切换至新域名。

## 用户故事

1. 作为家长，我想通过备案后的 HTTPS 小程序 API 登录，以便安全地使用拍题、作业批改和错题本功能。
2. 作为家长，我想继续使用微信登录，以便无需重新注册独立账号。
3. 作为家长，我想拍摄或选择图片并直接上传至受保护的对象存储，以便不受 API 服务器带宽和请求体大小限制。
4. 作为家长，我想让上传凭证只允许写入当前识别任务的图片路径，以便其他人不能借用凭证上传或覆盖文件。
5. 作为家长，我想在单题和整页作业识别时立即获得任务状态，以便识别较慢时仍可继续等待或恢复页面。
6. 作为家长，我想让识别在后台完成，以便 DeepSeek 响应慢时不导致小程序请求超时。
7. 作为家长，我想在识别失败时得到可行动的重试、重新拍摄或手动录入选项，以便不被服务故障阻塞。
8. 作为家长，我想只有自己的账户能读取自己的识别任务、图片关联和结果，以便保护孩子学习数据。
9. 作为家长，我想在 AI 识别完成后继续确认题干、作答和批改结论，以便 AI 初判不会直接改变错题本和学习统计。
10. 作为运营人员，我想识别任务在 API 服务重启后仍可被 Worker 完成或重试，以便避免丢失家长提交的图片。
11. 作为运营人员，我想在日志中按请求 ID、任务 ID 和发布版本排查 API、COS、MySQL、SCF 与 DeepSeek 故障，以便快速定位问题。
12. 作为运营人员，我想不在日志、镜像、小程序或仓库中暴露微信密钥、DeepSeek 密钥、COS 临时密钥、openid、图片或临时 URL，以便满足最小暴露原则。
13. 作为发布负责人，我想通过固定镜像和函数版本发布并可回滚，以便问题发生时能恢复上一稳定版本。
14. 作为发布负责人，我想在备案完成前完成受控环境验证，以便域名生效后只进行低风险切换。
15. 作为基础设施维护者，我想让数据库仅经私网访问，以便避免将 MySQL 暴露到公网。
16. 作为基础设施维护者，我想让 SCF 通过受控 NAT 出口访问 DeepSeek，以便出网路径和安全策略可预测。
17. 作为基础设施维护者，我想由 CLS 集中保存脱敏运行日志，以便不依赖 CVM 容器生命周期保留诊断证据。
18. 作为产品负责人，我想从全新生产环境开始而不迁移旧数据，以便降低上线复杂度和历史系统依赖。

## 实施决策

- 微信云托管、CloudBase Storage、云托管私网域名、`wx.cloud.uploadFile`、`cloud://` 文件 ID 与云托管内部图片代理不再作为生产依赖。旧环境已销毁，不做数据或图片迁移。
- 新环境的核心拓扑为：备案域名到 CVM Nginx；Nginx 到 Docker 化 Node.js API；API 和 SCF 到同地域 TencentDB/CynosDB MySQL；小程序与 Worker 到 COS；Worker 经 NAT 调用 DeepSeek；日志进入 CLS。
- CVM 采用现有 2 核 2 GB 起步规格，只运行 Nginx 和无状态 API 容器。MySQL、图片、异步执行和日志不得依赖 CVM 本地磁盘。镜像构建在 GitHub Actions 或受控构建环境完成，不在生产 CVM 构建。
- Nginx 终止 TLS，监听 443；80 仅用于证书校验和跳转 HTTPS。API 容器只暴露给 Nginx 的本机或私网端口。Nginx 配置请求体大小限制、基础速率限制、健康检查转发和安全响应头。
- 域名备案完成并签发腾讯云 SSL 证书后，API 使用固定 HTTPS 域名。小程序生产配置仅允许该域名；未备案期间只进行不面向真实用户的受控联调，不将临时隧道作为生产链路。
- 保持现有微信 `code2Session` 登录语义。AppID、AppSecret 仅由 API 运行环境持有；API 验证微信 `code` 后在新 MySQL 创建账户和会话。不得在小程序、前端日志或 COS 元数据写入 AppSecret。
- 新建私有 COS Bucket。API 签发有效期不超过 15 分钟、限定单一 object key 与必要内容类型/大小条件的临时上传授权；小程序直传 COS 后仅提交 API 签发的 upload token 与匹配的 object key。API 不得接受任意 bucket、object key、公开 URL 或客户端指定的对象归属。
- COS object key 按业务所有权和任务隔离。API 在创建识别任务前验证 upload token、对象 key、孩子档案、草稿/作业关联、会话归属及幂等键。图片不经过 CVM API 请求体，不在任务日志中记录图片内容、临时 URL 或临时凭证。
- 识别任务继续使用 MySQL 持久化状态机：`pending`、`processing`、`succeeded`、`failed`。单题与整页作业共用创建、领取、结果、过期、重试、配额和授权规则；保留各自的结构化识别结果和家长确认流程。
- API 创建任务后异步调用指定 SCF Worker，并立即返回 `202` 与任务 ID。第一版不引入消息队列；异步投递失败必须持久化为可诊断状态，任务查询超时应产生可行动的业务失败结果。
- SCF Worker 只接收任务 ID，从 MySQL 原子领取任务，并用自身最小 CAM 角色访问任务对应 COS 对象。Worker 不接收图片正文、用户会话、微信 code、COS 临时凭证或 API 密钥。Worker 最多自动重试两次可恢复故障，并将脱敏错误代码、尝试次数与耗时写回 MySQL。
- SCF、CVM、MySQL 与 COS部署在同一地域。CVM 和 SCF 经 VPC 私网访问 MySQL；MySQL 禁止公网访问。SCF 通过 NAT 网关访问 DeepSeek。安全组仅允许必要的 443/80 入站、受控 SSH 管理源、CVM/SCF 到 MySQL 3306 的私网访问及必要出站。
- DeepSeek 保持现有视觉识别提供方。Worker 使用 COS 受控读取/短期 URL 或等效受限访问方式取得图片，调用应设置超时、结构化输出限制和可重试错误分类；不得记录图片、完整提示词、完整模型输出或密钥。
- TCR 保存 API 镜像，GitHub Actions 按发布版本构建与推送。生产发布使用固定版本标签，禁止仅依赖 `latest`。API 启动日志必须记录版本、分支、commit 与运行模式；发布流程必须保留上一稳定镜像和 Worker 包以支持回滚。
- CLS 集中采集脱敏 API、Worker 与发布日志。必须记录请求 ID、任务 ID、状态码、耗时、错误类别、重试次数、COS 操作结果和版本标识；不得记录微信 code、openid、密钥、临时 URL、图片内容或完整模型响应。
- 生产密钥通过受限权限的环境变量管理，第一版可使用仅 CVM/SCF 可读的生产配置；后续可迁移至腾讯云 Secrets Manager。密钥不得写入 Docker 镜像、TCR 层、GitHub Actions 日志、代码仓库或小程序。
- 生产运行配置至少覆盖：数据库私网连接、COS Bucket/地域、COS 临时授权角色、SCF 函数名/地域、DeepSeek 配置、微信 AppID/AppSecret、会话密钥、CLS 配置、发布版本信息和 Nginx 站点配置。所有配置需要启动期校验和脱敏诊断。
- 最高验证 seam 是 HTTPS API 合同：登录后申请受限上传授权、上传指定 COS 对象、创建识别任务、异步获得终态、读取结果，并完成既有家长确认流程。该 seam 以外部可观察行为验证 API、COS、SCF、MySQL 和小程序协作，不耦合云 SDK 内部调用。

## 测试决策

- 测试断言面向外部行为、授权边界、状态合同和持久化结果，不绑定 SDK 调用顺序、环境变量读取顺序或容器内部实现。
- HTTP 合同测试覆盖微信登录、会话授权、受限上传凭证申请、无效/过期/越权 upload token、任意 object key 拒绝、任务创建幂等、`202` 任务响应、任务状态归属、终态结果和用户可行动错误。
- COS 集成测试覆盖临时授权只能上传已签发的 object key、超时后不可用、内容类型/大小限制生效、Worker 可读任务对象、清理策略可删除过期临时图片。测试使用隔离 Bucket 前缀和虚构图片 fixture。
- Worker 集成测试覆盖 MySQL 原子领取、COS 获取、DeepSeek 成功写回、超时/网络/429/5xx 重试、不可恢复失败、最大三次尝试、任务超时和发布版本日志。不得使用真实生产密钥或未成年人图片。
- 小程序流程测试覆盖 COS 直传、上传完成后创建任务、轮询恢复、单题确认、作业逐题确认、失败重试、手动录入降级和生产 API 域名配置。
- 部署验证覆盖 Docker 镜像启动、Nginx HTTPS/健康检查/限流、CVM 到 MySQL 私网连通、SCF 到 MySQL 与 COS 授权、SCF 经 NAT 调用 DeepSeek、CLS 检索请求/任务关联日志以及固定版本回滚。
- 安全验证覆盖 MySQL 无公网入口、SSH 仅允许管理 IP、API 容器无公网直连端口、COS 不公开读写、CAM 角色最小权限、日志与镜像中没有密钥或敏感用户数据。
- 现有学习闭环测试仍是回归基线：AI 初判不直接创建错题，家长确认后才更新错题、正确练习证据、掌握度、复习计划和周报。

## 不在范围内

- 不迁移已经销毁微信云托管环境的用户、MySQL 数据、图片、环境变量、域名或日志。
- 不引入消息队列、Kubernetes/TKE、多地域容灾、自动跨地域故障转移或高可用集群。
- 不更换 DeepSeek，也不增加第二个视觉模型供应商。
- 不在本期建设独立运营控制台、任务历史长期展示、订阅消息、CDN 优化、WAF 或商业化计费。
- 不将家庭 NAS、临时隧道、CVM 本地磁盘或公网 MySQL 作为生产数据链路。
- 不在备案完成前将临时测试地址配置为小程序生产合法域名。

## 进一步说明

- 由于尚未上线，采用全新环境而非并行迁移或历史数据同步。发布前仍需完成完整联调和回滚演练。
- 2 核 2 GB CVM 适用于低并发 API 起步；容器资源、CPU、内存、连接数和识别失败率必须接入监控。达到容量阈值后优先升级到 2 核 4 GB 或迁移 API 到容器平台，数据库和对象存储不依赖该迁移。
- 不引入消息队列的前提是 SCF 异步投递、MySQL 任务状态机和重试策略能覆盖当前预期流量。出现持续投递失败、明显积压或需要削峰时，另立需求评估消息队列。
