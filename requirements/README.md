# 需求版本索引

本目录是产品需求的唯一事实来源，供产品、设计和开发模型共同读取。

## 命名规则

- 文件名：`PRD-<编号>-<主题>-v<主版本>.<次版本>.<修订版本>.md`
- 版本规则：新增不兼容范围或产品阶段时升级主版本；新增功能升级次版本；文字澄清或小范围修订升级修订版本。
- 每次变更均须在对应文档的“版本记录”中新增一行，说明变更、原因和影响范围。
