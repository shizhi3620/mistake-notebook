# ADR 0001: 家长确认作为作业批改学习记录的依据

## Status

Accepted

## Context

数学作业批改需要从整页图片中识别多道题和孩子的手写作答。手写识别、题目切分和 AI 解题均可能不可靠；若直接把 AI 输出计入错题本、掌握度和薄弱点，会把模型错误记录为孩子的学习表现。

## Decision

作业批改将 AI 输出定义为初判，家长对每道题的确认或改判定义为已确认批改结果。

只有已确认错误题创建错题和复习计划；已确认正确题作为正确练习证据参与掌握度；待确认题不参与统计。家长可以后续修改结果，统计以最新的家长确认结果重算。AI 推导答案必须标识为 AI 推导，不能表示为教师标准答案。

## Consequences

批改流程需要支持单题确认、改判和高置信度题目的受限批量接受。模型输出不能直接成为学习记录，因而实现和交互成本更高；作为交换，弱项和掌握度数据保持可解释且可由家长纠正。
