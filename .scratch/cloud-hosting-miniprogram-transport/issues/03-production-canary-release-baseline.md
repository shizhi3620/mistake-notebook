# 03 — 单生产环境灰度发布操作基线

**What to build:** 为唯一生产云托管环境形成可执行发布清单，使发布负责人可以先用指定 `openid` 验证版本，再逐步扩大流量并在异常时回退，同时不将默认或自定义域名作为正式小程序 API 入口。

**Blocked by:** 01 — 小程序云托管传输切换; 02 — 云托管调用兼容与回归保护

**Status:** resolved

- [x] 发布清单明确本地 Docker、自动化测试和生产云托管灰度各自必须完成的验证项目。
- [x] 发布清单定义 `openid` 白名单验证、5%、25%、100% 放量、观察窗口、关键异常条件和立即回退动作。
- [x] 发布清单明确云托管服务、环境 ID、服务版本和小程序体验/正式版之间的对应关系。
- [x] 发布清单明确默认域名与自定义域名不作为正式小程序业务入口，并记录公网访问设置的复核责任。
