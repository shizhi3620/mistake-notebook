# 02 — 云托管调用兼容与回归保护

**What to build:** 为小程序 API 客户端建立传输无关的行为验证，使体验版和正式版迁移到云托管后，家长仍能可靠登录、恢复 session 和幂等提交；低版本微信获得可操作的升级提示。

**Blocked by:** 01 — 小程序云托管传输切换

**Status:** done

- [x] 验证开发版使用 HTTPS API，体验版和正式版使用云托管调用，且外部请求契约一致。
- [x] 验证服务标识、`/api` 路径、Bearer token、幂等键和 JSON body 在云托管调用中完整传递。
- [x] 验证首次登录和 session 失效后的重试在两种传输方式下均返回既有用户可见结果。
- [x] 验证基础库低于 `2.13.1` 时不发起网络调用，并返回升级微信的明确提示。
