# 01 — 整页作业图片上传与区域检测

**What to build:** 家长可从拍照或相册选择一张整页作业图片并提交；系统识别图片中的题目候选区域，最多返回 20 个区域。图片中的姓名、页码、草稿和其他非作业内容不得被默认当作题目。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 批改作业页面提供拍照和相册入口，并保留手动录入入口
- [ ] 图片在客户端压缩，上传请求遵守云托管 100 KB 限制
- [ ] 整页分析返回最多 20 个候选区域及基础题型信息
- [ ] 无法检测区域时进入手动框选，不把整页直接当作一道题
- [ ] 上传或分析失败提供重试、重新选图和手动录入
- [ ] HTTP 与适配器测试覆盖成功、超限、无区域和失败场景
