# 03 — AI 初判与家长逐题确认

**What to build:** 每道识别题展示题干、学生答案、AI 正确性初判、参考答案、理由、知识点和错因建议；家长可修改内容并确认正确、错误或待确认。

**Blocked by:** 02 — 题目区域编辑与逐题识别

**Status:** ready-for-agent

- [ ] 逐题结果沿用作业候选数据契约并支持低置信度
- [ ] 家长可修改题干、学生答案、知识点和错因
- [ ] 家长可逐题确认正确、错误或待确认
- [ ] 确认前 AI 结果不进入错题本、掌握度、复习计划或周报
- [ ] 确认错误后创建错题；确认正确不创建错题；待确认保持隔离
- [ ] 确认接口支持幂等重试和孩子档案归属校验
- [ ] 学习闭环和 HTTP 测试覆盖三种确认状态
