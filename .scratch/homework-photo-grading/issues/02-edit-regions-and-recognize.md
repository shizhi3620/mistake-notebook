# 02 — 题目区域编辑与逐题识别

**What to build:** 家长可在整页分析结果上删除、移动、缩放、合并或新增题目区域；确认区域后，系统逐题识别题干、题型和学生答案，并展示每题独立进度。

**Blocked by:** 01 — 整页作业图片上传与区域检测

**Status:** ready-for-agent

- [ ] 区域坐标可在图片预览中编辑并保持与原图尺寸无关
- [ ] 支持删除、移动、缩放、合并和新增区域
- [ ] 确认区域后才开始逐题识别
- [ ] 每个区域生成独立题目识别结果和状态
- [ ] 单题识别失败可单独重试，不影响其他题目
- [ ] 图片和临时地址不写入日志，失败不留下可用半成品
- [ ] 小程序和 HTTP 测试覆盖区域编辑及逐题识别
