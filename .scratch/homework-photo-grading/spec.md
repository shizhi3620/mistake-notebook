# 整页作业拍照识别与逐题批改规格

**Status:** ready-for-agent

**Baseline:** `requirements/PRD-002-parent-homework-mistakes-v1.1.0.md` 与 `docs/adr/0001-parent-confirmed-homework-grading.md`。本规格补充并冻结整页作业批改的交互与技术范围。

## Problem Statement

当前“批改作业”页面只支持逐题手动录入，无法处理真实作业场景：一张图片可能包含多道不同题型，也可能混入姓名、页码、草稿或其他非作业内容。若直接把整页交给单题识别或批改模型，容易产生错误题干、漏题、误识别和不应进入错题本的结果。

## Solution

支持家长拍照或从相册选择一张整页作业图片。系统先执行整页题目区域检测，返回最多 20 个候选区域。家长在预览页确认、删除、调整、合并或新增区域；若自动检测失败，可手动框选。确认区域后，系统逐题识别题干、题型、学生答案和解题信息，并给出 AI 初判。家长逐题确认“正确 / 错误 / 待确认”，只有确认后的结果才影响错题本和学习统计。任何阶段失败都保留重试、重新选择图片和手动录入入口。

## User Stories

1. 作为家长，我想拍摄一张整页作业，以便一次处理纸面上的多道题。
2. 作为家长，我想从相册选择作业图片，以便处理已经拍好的作业。
3. 作为家长，我想在上传前看到图片预览，以便确认拍摄内容清晰完整。
4. 作为家长，我想裁剪或旋转整页图片，以便去除姓名、页码和其他无关信息。
5. 作为家长，我想让系统自动框选题目区域，以便减少逐题手动框选的工作量。
6. 作为家长，我想查看候选区域编号和缩略图，以便知道系统识别了哪些题目。
7. 作为家长，我想删除误识别的区域，以便草稿、姓名和装饰内容不会进入批改。
8. 作为家长，我想调整区域边界，以便完整包含题干和学生作答。
9. 作为家长，我想合并被错误拆分的区域，以便一道题的题干和答案保持完整。
10. 作为家长，我想新增手动区域，以便处理 AI 漏掉的题目。
11. 作为家长，我想在系统没有识别出区域时手动框选，以便流程仍可继续。
12. 作为家长，我想确认区域后再开始逐题识别，以便避免无效的模型调用。
13. 作为家长，我想看到每道题的识别进度，以便知道批改是否仍在进行。
14. 作为家长，我想查看识别出的题干、题型和学生答案，以便发现 OCR 错误。
15. 作为家长，我想修改题干和学生答案，以便批改建立在正确内容上。
16. 作为家长，我想看到 AI 对每道题的正确、错误或无法判断初判，以便快速了解作业情况。
17. 作为家长，我想看到参考答案和简要判断理由，以便核对 AI 的初判。
18. 作为家长，我想看到主知识点、次知识点和错因建议，以便理解错误来源。
19. 作为家长，我想逐题确认正确、错误或待确认，以便保留对学习记录的最终决定权。
20. 作为家长，我想在 AI 无法可靠判断时选择待确认，以便不把不确定结果写入错题本。
21. 作为家长，我想确认错误题后自动进入错题本，以便继续后续复习闭环。
22. 作为家长，我想确认正确题但不生成错题，以便作业结果与错题记录分离。
23. 作为家长，我想在识别失败时重试当前题，以便不必重新上传整页图片。
24. 作为家长，我想在图片过大或网络失败时获得明确提示，以便知道如何处理。
25. 作为家长，我想随时改用手动录入，以便技术识别不可用时仍能完成作业批改。
26. 作为家长，我想分批上传多页作业，以便每次处理一页并控制等待时间。

## Implementation Decisions

- 批改作业页面新增“拍照”和“从相册选择”入口，替代当前仅显示手动录入的首屏流程；手动录入保留为显式兜底入口。
- 采用两阶段 AI 流程：整页分析只返回候选题目区域及基础题型信息；用户确认区域后，逐题调用现有单题识别/批改能力。
- 整页分析接口最多返回 20 个候选区域。20 是技术保护阈值，不是用户业务配额；超过阈值时提示分批上传或缩小区域。
- 区域模型必须支持用户删除、移动、缩放、合并和新增；区域坐标使用图片归一化坐标，前端展示坐标与原图尺寸解耦。
- 整页分析没有结果时不得自动把整张图片当作一道题；页面直接进入手动框选或手动录入。
- 逐题识别结果沿用 `HomeworkRecognition` 结构，至少包含题干、学生答案、答案置信度、正确性初判、置信度、参考答案、推理说明和知识点建议。
- AI 输出始终是初判。家长确认前，候选题不得进入错题本、掌握度、薄弱点、复习计划或周报统计。
- 家长确认错误题时沿用现有作业候选确认接口；错误题缺少主知识点时继续要求补充或修改。
- 图片在客户端压缩并通过对象存储或受控临时 URL 传输；不得把整页原图长期保存在容器文件系统或小程序本地。
- 遵守微信云托管限制：单次 `CallContainer` 请求体控制在 100 KB 内，客户端调用超时控制在 15 秒内；耗时操作需要拆分为阶段请求。
- 所有识别请求必须经过现有家长会话和孩子档案归属校验，并使用现有 AI 频率/月度额度限制。
- 失败响应向用户提供重试、重新选择图片和手动录入，不暴露模型密钥、临时 URL、openid 或底层堆栈。
- 最高测试 seam 为 HTTP 作业批改接口与学习闭环的组合行为：输入图片/区域确认和家长确认动作，验证候选生成、待确认隔离及最终错题写入。

## Testing Decisions

- HTTP 测试验证整页分析请求能返回候选区域，区域确认后能创建作业 review；非法图片、空区域、超过 20 个区域和未登录请求必须得到明确错误。
- 学习闭环测试验证 AI 初判不会直接产生错题，家长确认错误后才创建错题，确认正确不会创建错题，待确认不会进入统计。
- 小程序流程测试验证拍照/相册入口、区域编辑状态、手动框选兜底、逐题识别提交、失败重试和手动录入导航。
- 图片传输测试验证压缩后的请求体低于 100 KB，且不把完整 Base64 或临时 URL 写入日志。
- 识别适配器测试使用固定 JSON fixture，验证多题区域、不同题型、无学生作答、低置信度和模型无效 JSON 的外部行为。
- 测试只断言用户可见结果和 API 合同，不绑定具体模型提示词、内部函数顺序或存储实现。
- 使用虚构孩子档案和脱敏测试图片；不得使用真实未成年人作业或身份数据。

## Out of Scope

- 一次上传多张图片或自动连续扫描整本作业。
- 自动把整页所有题目直接批改并跳过区域确认。
- 教师端批改、班级统计、成绩排名和自动提交作业。
- 自动代写答案或替学生生成可直接提交的作业。
- 数学以外学科的整页识别。
- OCR 结果永久存储、原图公开分享或用于模型训练。

## Further Notes

- 该规格与 PRD-002 的整页图片需逐题选择/裁剪要求一致，并遵循 ADR-0001 的家长最终确认原则。
- 识别服务不可用时，手动录入必须保持可用，且失败不应留下可被误认为已批改的半成品记录。
