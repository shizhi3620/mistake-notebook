# 02 — 部署 CVM HTTPS API 入口

**What to build:** 让备案域名的 HTTPS 请求安全地进入 CVM 上的 Docker API，并使 API 服务具备健康检查、基础限流、版本可见性和可回滚部署边界。

**Blocked by:** 01 — 建立普通腾讯云生产基础设施基线.

**Status:** ready-for-human

- [ ] Nginx 终止 TLS、处理证书校验和 HTTP 到 HTTPS 跳转，并仅将业务流量代理到本机或私网 API 容器端口。
- [ ] API 容器不直接暴露公网端口，健康检查、请求体限制、基础限流和安全响应头按生产要求生效。
- [ ] 域名、证书与小程序生产调用切换条件被记录；备案完成前仅支持受控联调。
- [ ] 健康检查和错误响应不暴露密钥、内部地址或实现细节。
