# 04 — 实现 COS 受限直传图片闭环

**What to build:** 让家长的小程序获得短期、单对象受限的上传授权并直传 COS，随后由 API 安全确认图片属于当前草稿或作业任务。

**Blocked by:** 01 — 建立普通腾讯云生产基础设施基线; 03 — 迁移 API 与微信登录至新 MySQL.

**Status:** ready-for-human

- [ ] 登录家长可为单题和整页作业申请有效期不超过 15 分钟的上传授权，授权仅允许指定 object key、内容类型和大小范围。
- [ ] 小程序可直传 COS，随后只提交 API 签发的 upload token 与匹配 object key；API 拒绝任意 bucket、对象路径、公共 URL、过期或越权令牌。
- [ ] 图片不经过 API 请求体；任务和运行日志不记录图片正文、COS 临时凭证或临时 URL。
- [ ] 取消、失败和过期上传遵守既有图片保留与清理规则，不影响已确认错题的长期图片策略。
