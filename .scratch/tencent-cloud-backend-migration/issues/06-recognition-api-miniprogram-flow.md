# 06 — 接通新环境的异步识别任务 API 和小程序流程

**What to build:** 让拍一道题和批改作业在新生产架构中完成直传、创建任务、轮询、恢复、失败降级和家长确认，不再依赖云托管或 CloudBase 文件 ID。

**Blocked by:** 03 — 迁移 API 与微信登录至新 MySQL; 04 — 实现 COS 受限直传图片闭环; 05 — 迁移异步识别 Worker 至普通腾讯云 COS.

**Status:** ready-for-human

- [ ] 单题和整页作业任务创建立即返回 `202`、任务 ID 和可轮询状态；同一家庭并发、幂等键和拍题额度保持既有规则。
- [ ] API 异步投递 Worker，任务状态仅对所属家长可读；任务完成后分别进入题干确认和逐题批改确认流程。
- [ ] 小程序在页面返回时恢复未完成任务，在成功、失败、卸载或替换任务时停止轮询。
- [ ] DeepSeek 或基础设施故障显示可行动的重试、重新拍摄或手动录入提示；AI 初判仍不直接写入学习统计。
