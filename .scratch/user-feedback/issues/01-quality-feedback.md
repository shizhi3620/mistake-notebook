# 01 — 单题讲解质量反馈

**What to build:** 家长可以针对一次具体的单题讲解提交“有帮助”或“有问题”反馈，帮助定位题干、答案、讲解和难度质量问题。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 家长可对具体单题讲解提交 `helpful` 或 `problematic` 反馈。
- [ ] `problematic` 可选择题干、答案、讲解、难度中的一个或多个问题项。
- [ ] 反馈关联正确的家长账户、孩子档案、题目、讲解版本、模型版本、请求版本和提交时间。
- [ ] 说明文字可选，长度限制为 1–500 字；非法长度或问题项被拒绝并返回现有错误结构。
- [ ] 低置信度、失败或已完成的单题讲解均可按规则提交反馈，但不能关联其他账户的结果。
- [ ] 重复请求按 `Idempotency-Key` 返回首次结果，不创建重复反馈。
- [ ] `LearningLoop` 公共接口和 HTTP seam 覆盖正常、校验失败、越权和幂等场景。
