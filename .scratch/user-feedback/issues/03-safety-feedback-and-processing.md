# 03 — 内容安全反馈与内部处理

**What to build:** 家长可以举报单题讲解中的不当、危险、歧视或不适合未成年人的内容；运营审核员可以在独立高优先级队列中处理反馈并留下审计记录。

**Blocked by:** 01 — 单题讲解质量反馈; 02 — 通用功能反馈

**Status:** done

- [x] 家长可对具体单题讲解提交 `safety` 反馈，说明文字必填且限制为 1–500 字。
- [ ] 安全反馈关联正确的家长账户、孩子档案、题目、讲解版本、模型版本、请求版本和提交时间。
- [x] 安全反馈进入独立的高优先级处理队列或视图，不与普通质量/功能反馈混排。
- [x] 反馈支持内部状态 `new`、`reviewing`、`resolved`、`rejected`，非法状态流转被拒绝。
- [x] 运营审核员可添加内部备注；状态和备注变更保留审计信息，用户端只显示“反馈已收到”。
- [x] 反馈正文支持注入式未成年人内容安全检测；检测失败拒绝提交且不影响原学习流程。
- [x] 管理端只暴露处理案件所需的最小数据，跨账户访问被拒绝。
- [x] 覆盖安全反馈提交、优先级标记、状态流转、备注审计、检测失败和幂等测试。
