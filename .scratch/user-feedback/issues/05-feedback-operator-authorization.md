# 05 — 反馈运营审核授权

**What to build:** 为反馈查询、状态流转和内部备注建立独立的运营审核授权边界，使普通家长只能提交反馈和看到提交确认，运营审核员才能处理内部队列。

**Blocked by:** 03 — 内容安全反馈与内部处理

**Status:** ready-for-agent

- [ ] 定义独立的运营审核身份或服务凭证，不复用家长会话权限。
- [ ] 普通家长不能查询全量反馈、读取内部备注或修改处理状态。
- [ ] 运营审核员可按类型、优先级和状态查询反馈，并仅看到处理案件所需的最小数据。
- [ ] 运营审核员可将反馈从 `new` 流转到 `reviewing`、`resolved` 或 `rejected`，并添加内部备注。
- [ ] 状态和备注变更记录操作者、时间和变更前后值，形成审计记录。
- [ ] 未授权、越权和失效运营凭证返回稳定错误结构，且不泄露反馈内容。
