# 06: 首页学习待办与个人成长

**What to build:** 家长或孩子打开已建立档案的小程序时，能立刻看到当前孩子今天应做的复习、最近错题和个人学习进展，并可直接开始学习。

**Blocked by:** 04: 错题本浏览、检索与数据控制; 05: 自适应复习闭环.

**Status:** resolved

- [x] 无孩子档案时首页只引导创建档案；有档案时首屏同时显示“讲解一道题”和“今日待复习”。
- [x] 首页展示当前孩子、最近错题与七日学习摘要，并能安全切换到有效档案或在档案被删除后回退。
- [x] 用户能从待办直接进入正确孩子的今日复习流程，完成后首页待办和摘要同步更新。
- [x] 完成复习形成仅属于该孩子的连续记录或成长记录；不呈现排行榜、PK 或跨孩子比较。
