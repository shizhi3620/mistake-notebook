# 03: 适龄讲解与确认错题

**What to build:** 家长或孩子确认一至九年级数学题后，获得按年级组织的引导式讲解与变式练习，并将确认的错误沉淀为包含知识点和错因的错题记录。

**Blocked by:** 01: 家长登录与孩子档案; 02: 拍题、裁剪与题目确认.

**Status:** resolved

- [x] 讲解按“先想一想、解题思路、分步过程、最终答案”展示，最终答案默认折叠；家长可选择是否允许直接展开完整答案。
- [x] 内容以中国大陆一至九年级通用数学知识点体系和所选年级为依据，并包含可完成的同类变式练习。
- [x] 用户可附加或填写自己的作答、确认该题为错题，并在作答识别不清时跳过步骤分析。
- [x] 每个保存错题关联一个主知识点、至多两个次知识点和可修改的错因；不可靠题目不生成伪确定答案，也不进入错题统计。
