# 02: 拍题、裁剪与题目确认

**What to build:** 已确认的家长或其家庭设备上的孩子能够拍摄或选择一张数学题图片，先在本地裁剪、旋转和确认，再安全上传并编辑 OCR 识别结果。失败与低置信度始终有可靠的替代路径。

**Blocked by:** 01: 家长登录与孩子档案.

**Status:** resolved

- [x] 用户主动选择“拍照”或“从相册选择”后才请求对应权限；拒绝权限时提供开启指引和手动录入替代路径。
- [x] 图片预览支持裁剪、旋转、重选，并提示只保留一道题且遮挡姓名等无关信息。
- [x] 上传使用当前家长、单对象、短时有效的凭证；取消、失败和凭证过期不创建空题目，可恢复本地草稿后重传。
- [x] 识别题干、公式与图片范围在讲解前可编辑确认；低置信度明确标识并支持重拍或手动修改。
