# 01: 家长登录与孩子档案

**What to build:** 家长能够通过微信进入产品、完成监护人确认，并创建、编辑、切换自己的孩子档案。未确认或不具备绑定关系的访问者不能创建档案或读取任何孩子学习数据。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 首次登录仅建立待确认家长账户；完成监护人确认前，产品仅展示介绍内容。
- [x] 已确认家长可创建和管理多个孩子档案，档案仅收集昵称、年级、地区和可选教材版本。
- [x] 每次孩子资源访问校验当前家长绑定关系；小程序重新打开时安全恢复上次选择的有效档案。
- [x] 微信平台身份标识与会话凭证不返回客户端、不写入日志；会话失效与无权限状态提供可理解的恢复路径。
