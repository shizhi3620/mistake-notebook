# 08: 可选复习提醒

**What to build:** 家长能够主动选择微信订阅提醒，在需要复习时收到低频、隐私安全的入口通知；即使提醒不可用，学习计划仍在小程序内正常运行。

**Blocked by:** 01: 家长登录与孩子档案; 05: 自适应复习闭环.

**Status:** resolved

- [x] 家长只能从提醒设置的明确入口了解用途、频率和关闭方式后请求订阅授权；首次登录和拍题流程不强制请求。
- [x] 提醒开启时，系统在家长设定时间评估待复习事项；同一孩子在自然日最多发送一条。
- [x] 通知只包含孩子昵称（如有）、待复习题数和受授权保护的跳转路径，不含题干、答案、错因或成绩。
- [x] 授权拒绝、模板不可用或发送失败时不骚扰重试且不影响复习状态；关闭提醒、撤回授权或删除档案后立即停止关联提醒。

## Comments

- 2026-08-26: 领域层完成（`test/reminders.test.ts` 3 个测试通过）。提醒默认关闭，`updateReminderSettings` 是唯一入口且仅在家长显式调用时开启（登录与拍题流程无任何提醒请求，授权文案属客户端）。`dispatchDueReminders` 按 Asia/Shanghai 在设定整点后评估待复习，同一孩子同一自然日（含失败）只记录一次发送，无待复习则不发送不占额度。通知负载仅含孩子昵称、待复习题数与 `entryPath`（需会话的跳转路径），测试断言不含题干与错因。发送通道为注入的 `reminderSender` 端口：未配置或抛错标记 `failed`、当日不再重试、复习计划不受影响。`enabled: false` 立即停发；删除孩子档案或账户级联删除设置与发送记录，关联提醒立即停止。
