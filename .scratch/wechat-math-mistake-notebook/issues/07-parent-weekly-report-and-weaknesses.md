# 07: 家长周报与薄弱知识点

**What to build:** 家长能够查看一份支持性周报，理解孩子本周学习量、真正不稳定的知识点和下一周可执行的复习重点。

**Blocked by:** 05: 自适应复习闭环.

**Status:** resolved

- [x] 周报展示本周新增错题、完成复习、掌握度变化、下周复习计划和一条可执行建议。
- [x] 薄弱点根据错误频率、复习表现和变式表现共同排序，而非只按错题数量；最多展示三项优先知识点。
- [x] 报告不包含与其他孩子的比较、排名或贬损性标签，并对无数据状态如实说明。
- [x] 家长可从报告进入相关知识点或待复习内容，且只能查看当前已授权孩子的数据。

## Comments

- 2026-08-26: 领域层完成（`test/weekly-report.test.ts` 3 个测试通过）。`getWeeklyReport` 按上海日历的周一至周日聚合：本周新增错题、完成复习、掌握度净变化（正/负复习次数）、下周到期复习数与重点知识点、一条可执行建议。薄弱点评分 = 2×错题数 + 2×自评"未掌握"次数 + 2×变式答错次数 + 4×(1−平均掌握度)，确定性排序取前三；测试证明它不同于纯错题数量排序。每条薄弱点携带 mistakeIds 供客户端跳转到相关错题/待复习。无数据时 `empty: true` 并如实建议先拍题；每份报告附"仅含该孩子本人记录、不包含任何排名或与其他孩子比较"说明。访问经 `findChildProfileForGuardian` 校验，其他家长与其他孩子的数据不可见。
