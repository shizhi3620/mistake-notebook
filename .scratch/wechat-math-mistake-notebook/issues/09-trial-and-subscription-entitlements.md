# 09: 免费试用与订阅权益

**What to build:** 家长能在免费额度内体验核心闭环，明确了解升级可获得的能力；产品能够一致地执行权益，但首发不处理实际支付。

**Blocked by:** 01: 家长登录与孩子档案; 03: 适龄讲解与确认错题; 07: 家长周报与薄弱知识点.

**Status:** resolved

- [x] 免费账户拥有明确且可追踪的月度拍题额度和基础复习能力，达到额度后得到可理解的提示而非静默失败。
- [x] 订阅权益可控制更多拍题次数、完整周报、更多变式练习和多孩子档案，不影响已存在学习数据的访问与删除权。
- [x] 权益判断在所有入口保持一致，且账户之间不能相互借用或越权获得权益。
- [x] 不在本任务中实现微信支付、自动续费或商城；这些能力须经后续独立规格确认。
