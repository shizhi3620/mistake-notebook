# 微信数学错题本小程序首发规格

**Status:** ready-for-agent

**Baseline:** PRD-002《家长作业讲解与错题本》v1.1.0。本规格补充并冻结首发产品决策；如与基线冲突，以本规格为准。

## Problem Statement

家长需要帮助小学到初中阶段的孩子发现数学学习中的薄弱环节，但纸质错题难以整理、复习容易中断，且家长很难判断孩子是否真正掌握了同类题。孩子拍下错题后，需要得到符合其年级的引导式讲解，将错题归入可靠的知识点体系，并在合适的时间重新练习。家长还需要一份不制造排名焦虑、可据此采取行动的学习摘要。

## Solution

提供面向家长的微信小程序。家长以微信身份登录并完成监护人确认后，为一个或多个孩子建立学习档案。家长或孩子在家庭设备上拍摄、裁剪并确认一道数学错题；系统识别题目和作答，按所选年级生成先提示、后分步、最后答案的讲解及变式练习。确认后的错题按主、次知识点归档，学习闭环根据错题、复习表现和变式题结果计算掌握度，并安排动态的艾宾浩斯节奏复习。家长在小程序内查看待复习事项和周报，并可选择接收低频微信订阅提醒。

首发支持中国大陆一至九年级数学，以国家课程标准和通用年级知识点体系为主；地区与可选教材版本仅用于改善表述和匹配度，不作为内容可用性的硬前提。

## User Stories

1. 作为家长，我想通过微信登录小程序，以便不必另行注册账号。
2. 作为家长，我想在首次使用时确认监护人身份和隐私摘要，以便在孩子数据被处理前作出明确决定。
3. 作为家长，我想在未同意前只能浏览产品介绍，以便不会意外上传孩子的数据。
4. 作为家长，我想为每个孩子创建独立档案，以便分开管理兄弟姐妹的学习记录。
5. 作为家长，我想仅填写孩子昵称、年级、地区和可选教材版本，以便获得个性化内容而不过度提供个人信息。
6. 作为家长，我想在档案间切换并在下次打开时恢复上次选择，以便快速继续管理同一孩子。
7. 作为家长，我想从首页拍摄一道题或从相册选图，以便方便地录入错题。
8. 作为家长，我想在上传前裁剪、旋转或重选图片，以便只保留一道题并遮挡姓名等无关信息。
9. 作为家长，我想在尚未主动选择图片前不被请求相机或相册权限，以便保有权限控制权。
10. 作为家长，我想在图片上传或识别失败时重试或手动录入，以便不会因为技术失败丢失学习机会。
11. 作为学生，我想查看并修改识别出的题干、公式和图片区域，以便后续讲解建立在正确题目上。
12. 作为学生，我想上传或填写自己的作答，并在必要时标记该题已经确认是错题，以便系统能解释可能的错误步骤。
13. 作为学生，我想在作答识别不清时跳过作答分析，以便仍能获得题目讲解和复习计划。
14. 作为学生，我想先看到启发式提示，以便先尝试独立思考。
15. 作为学生，我想按需展开解题思路、分步过程和最终答案，以便不会一开始就依赖答案。
16. 作为学生，我想获得与我当前年级相符的数学讲解，以便不会因语言或方法超前而难以理解。
17. 作为学生，我想在讲解后完成一道同类变式练习，以便验证自己是否理解而非只看懂答案。
18. 作为家长，我想选择是否允许直接查看完整答案，以便按孩子的学习习惯调整引导力度。
19. 作为家长，我想在系统无法可靠解析题目或答案时得到明确提示，以便不会把不可靠结论当成正确答案。
20. 作为家长，我想将无法可靠解析的题保留为待确认记录，以便重拍或手动修改后继续处理。
21. 作为家长，我想把确认的错题保存进错题本，以便形成长期可复习的学习资产。
22. 作为学生，我想看到每题的主知识点和至多两个次知识点，以便理解错误关联的学习内容。
23. 作为家长，我想在系统建议错因后修改它，以便学习记录反映真实原因。
24. 作为家长，我想按知识点、错因、日期和掌握状态筛选并搜索错题，以便快速定位需要处理的题目。
25. 作为家长，我想将疑似重复的错题决定是否合并，以便避免错误去重造成学习记录丢失。
26. 作为学生，我想在首页看到今天必须复习的题目数量，以便知道下一步该做什么。
27. 作为学生，我想在一次复习中先回忆知识点或解题思路，再完成原题或变式题并自评掌握程度，以便形成有效复习。
28. 作为学生，我想在复习后看到下一次复习安排，以便理解学习节奏。
29. 作为家长，我想让复习间隔随掌握情况调整，以便不把相同频率施加给已掌握和仍薄弱的内容。
30. 作为家长，我想让系统从 1、2、4、7、15、30 天等初始间隔开始，以便以艾宾浩斯式节奏建立习惯。
31. 作为家长，我想看到由错误频率、复习表现和变式题表现共同得出的薄弱知识点，以便优先帮助真正不稳的部分。
32. 作为家长，我想查看不超过三项、附带可行动建议的周度薄弱点摘要，以便支持孩子而不制造焦虑。
33. 作为家长，我想查看本周新增错题、完成复习、掌握度变化和下周计划，以便了解学习过程。
34. 作为家长，我想在主动开启后于设定时间收到每天至多一条待复习提醒，以便形成习惯而不受打扰。
35. 作为家长，我想在没有订阅消息授权或通知发送失败时仍在小程序内看到待复习事项，以便提醒通道失效不影响计划。
36. 作为家长，我想随时关闭提醒或撤回授权，以便停止后续通知。
37. 作为家长，我想删除单题、单个孩子档案或全部账户数据，以便行使对孩子学习数据的控制权。
38. 作为家长，我想知道题目与照片不会被公开展示或用于训练，以便放心使用产品。
39. 作为家长，我想在免费额度内验证产品价值，以便决定是否订阅。
40. 作为家长，我想在订阅后获得更高使用额度、完整周报、更多变式练习和多孩子档案，以便持续使用完整能力。
41. 作为学生，我想获得连续复习和个人成长记录，以便保持动力而不被排名比较。
42. 作为家长，我不想看到排行榜、PK 或其他儿童比较功能，以便产品保持支持性学习氛围。

## Implementation Decisions

- 首发客户端为微信小程序，账户入口为微信授权登录；孩子不使用独立微信账号，所有操作处于已验证家长的家庭设备模式。
- 核心资源主体是家长账户及其已授权的孩子档案；每次读取、修改、提醒或跳转至孩子学习数据时都必须校验当前绑定关系。
- 一次录入在图片上传成功后才创建题目记录。图片使用一次性、短时、只允许当前用户上传单一对象的上传凭证；小程序不得持久保存图片 Base64。
- 题目识别结果必须在进入讲解前可编辑并由用户确认。低置信度或不支持的内容不得生成貌似确定的答案，改为待确认状态并提供重拍或手输路径。
- 讲解输出固定为“先想一想、解题思路、分步过程、最终答案”，最终答案默认折叠；讲解、答案与变式练习都要受年级、数学知识点和内容安全规则约束。
- 每题保存一个主知识点和最多两个次知识点。错因可由系统建议，但以家长/学生的最终修改为准。
- 采用一个**学习闭环编排模块**作为高层 seam。其 interface 接受已授权孩子和一个业务动作（确认错题、完成复习、请求周报），返回用户可见的学习状态。它封装题目状态流转、掌握度、复习日期、学习事件、周报输入及提醒资格；页面不得自行重算这些规则。
- 掌握度不是考试成绩或能力诊断。它由错题记录、复习自评和变式练习结果聚合得出，且需要在页面中说明含义。
- 首个复习计划以 1、2、4、7、15、30 天为默认间隔；编排模块依据后续表现缩短或延长下次间隔。未可靠确认的题目不参与薄弱点或复习统计。
- 提醒为可选的微信订阅消息通道，而不是任务状态的唯一来源。家长从设置页主动请求授权；后端定时评估时，单个孩子在自然日最多发送一条。消息只含昵称（如有）、待复习数和安全跳转路径。
- 周报展示新增与完成数量、最多三个优先知识点、掌握度变化、下周计划和行动建议；不包含其他孩子比较、排名或贬损标签。
- 数据最小化：不要求真实姓名、学校、精确位置、通讯录或儿童独立身份信息。照片提示裁掉无关信息，敏感数据加密存储；家长可以删除关联数据。
- 使用免费试用加订阅权益的产品模型。首版实现额度和权益判断；实际微信支付接入在留存验证后单独规划。
- 首发的信息架构保持首页、错题本、我的三个底部入口；讲解、OCR 确认、复习、周报、档案和隐私页为非底部页面。

## Testing Decisions

- 测试应通过学习闭环编排模块的 interface 验证外部行为：给定已授权孩子、题目确认或复习结果，断言返回的错题状态、掌握度表达、下一次复习、可见待办和周报内容；不测试内部模型调用、存储查询或页面实现细节。
- 为题目状态流转测试清晰题目、可编辑识别结果、低置信度、上传取消/过期与手动录入等行为，确保未完成上传不会创建空题目且不可靠内容不进入统计。
- 为复习编排测试默认间隔、不同掌握表现后的间隔变化、重复提交幂等性、待确认题排除、自然日与 Asia/Shanghai 时区边界。
- 为授权与隐私测试监护人确认前的拒绝访问、跨孩子档案访问拒绝、提醒关闭/撤回后的停止、删除后的旧提醒安全回退，以及敏感学习内容不会进入订阅消息。
- 为周报测试弱项排序的可解释输入、最多三项展示、无排名比较、缺失数据不伪造为零和下周行动建议。
- 为小程序流程进行端到端验证：创建档案、拍题、确认、讲解、保存、复习、查看周报、开启/关闭提醒及删除数据。使用虚构孩子资料和测试图片，不使用真实未成年人数据。
- 当前代码库没有同类应用测试先例；新增测试应以用户可见行为为准，并优先覆盖上述唯一高层 seam。

## Out of Scope

- 数学以外学科、教师端、学校合作入口和班级管理。
- 儿童独立微信登录、独立原生 App、网页端和跨平台客户端。
- 在线老师答疑、直播课程、教师批改、社群、排行榜、PK、公开分享学习数据和自动代写作业。
- 打印或导出错题本；作为首发闭环验证后的候选功能。
- 支付接入本身；首版仅定义免费额度及订阅权益边界。
- 绑定单一教材版本的完整内容覆盖、承诺答案绝对正确或以掌握度替代考试评价。
- 未经许可读取微信聊天记录、个人号机器人、协议逆向或任何绕过微信平台授权的通知能力。

## Further Notes

- 规格沿用 PRD-002 对微信登录、家庭设备模式、图片直传、订阅消息和未成年人保护的约束。
- 上线前需要完成适用的隐私、未成年人保护、生成式 AI 内容安全和微信小程序审核；不能通过产品逻辑绕过平台权限或审核限制。
- 小程序基础库版本、具体 OCR/AI 供应商、数据保留期限、成本上限与人工申诉服务等级尚未冻结，应在实现前作为技术与合规决策记录。
- 若未来扩展学科、教材强绑定、支付或教师协作，应建立新的规格和相应验收标准。
