# 05 — 识别任务可靠性、清理与上线验证

**What to build:** 异步识别在生产中具备可控并发、配额、过期清理、脱敏可观测性和端到端验证；单题和整页作业都能可靠完成或以可恢复方式失败。

**Blocked by:** 02 — 云函数 Worker 完成单题异步识别; 03 — 单题讲解页接入异步识别体验; 04 — 整页作业批改接入异步识别体验.

**Status:** ready-for-human

- [x] 同一家庭最多一个运行中的识别任务，所有任务纳入既有拍题额度；超出限制时不触发模型且保留手动录入入口。
- [x] 识别图片及临时引用在 24 小时后清理，任务、结果和脱敏审计信息在 7 天后清理，不影响既有规则允许长期保留的已确认错误题裁剪图。
