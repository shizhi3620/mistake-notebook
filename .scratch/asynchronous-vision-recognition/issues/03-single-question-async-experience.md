# 03 — 单题讲解页接入异步识别体验

**What to build:** 家长拍摄或选择一道题后立即看到识别中；小程序查询异步任务，成功后进入既有题干确认和讲解流程，失败时可明确重试、重新拍摄或手动录入。

**Blocked by:** 01 — 识别任务生命周期与安全查询; 02 — 云函数 Worker 完成单题异步识别.

**Status:** ready-for-agent

- [ ] 单题图片继续先上传对象存储，再创建异步任务；小程序不再等待同步视觉模型响应。
- [ ] 页面每秒查询一次任务，终态、页面离开或新任务替代旧任务时停止查询；返回页面可恢复同一未完成或已完成任务。
- [ ] 成功任务进入既有题干确认和讲解闭环，不改变家长对识别内容的修正权。
- [ ] 失败状态按业务文案提供重试、重新选择图片和手动录入，不显示供应商或云服务内部错误。
- [ ] 小程序流程测试覆盖识别中、成功恢复、失败操作、轮询停止及不会在同步请求中等待 DeepSeek。
