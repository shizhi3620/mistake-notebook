# 04 — 整页作业批改接入异步识别体验

**What to build:** 家长上传一页作业后，以对象存储图片引用创建异步作业识别任务；成功后进入既有逐题 AI 初判和家长确认流程，不再受 Base64 请求体和同步模型时限限制。

**Blocked by:** 01 — 识别任务生命周期与安全查询; 02 — 云函数 Worker 完成单题异步识别.

**Status:** ready-for-human

- [x] 批改作业只上传对象存储图片引用，不将整页 Base64 放入云托管请求；用户不会因请求体限制直接遇到“图片过大”。
- [x] Worker 按作业任务种类运行整页识别，并将不超过产品阈值的候选题、AI 初判和置信度写回任务。
- [x] 小程序显示任务进度、每秒查询、离开后恢复，以及成功后进入逐题查看和确认；手动录入始终可用。
- [x] 家长确认错误、正确或待确认后的错题、正确练习证据和统计行为继续遵循 ADR-0001。
- [ ] HTTP、学习闭环和小程序流程测试覆盖异步作业任务的成功、失败、权限和确认隔离行为。
