# 01 — 识别任务生命周期与安全查询

**What to build:** 家长可为已有的单题草稿或整页作业图片创建一个幂等的识别任务，并立即得到任务 ID；任务状态在刷新或重试后仍可安全查询，且只对所属家长账户可见。

**Blocked by:** None — can start immediately.

**Status:** ready-for-human

- [x] 单题与整页作业均可使用对象存储图片引用创建 `pending` 识别任务，并立即返回任务 ID，不在请求内调用视觉模型。
- [x] 任务持久化记录种类、关联资源、状态、尝试次数、结果或脱敏失败信息、过期时间与幂等键；同一账户和幂等键在终态前不会创建重复任务或重复扣减额度。
- [x] 查询接口只允许任务所属家长读取；越权、未登录、无效任务 ID 和无权孩子档案均不能泄露任务、图片或识别结果。
- [x] HTTP 合同测试覆盖创建、查询、幂等、授权边界及两种任务种类的外部行为。
