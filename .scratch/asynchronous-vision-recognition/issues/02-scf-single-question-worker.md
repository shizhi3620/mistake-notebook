# 02 — 云函数 Worker 完成单题异步识别

**What to build:** 家长创建单题识别任务后，云托管异步触发腾讯云函数 Worker；Worker 可靠取得对象存储图片引用，调用 DeepSeek，并将可供后续确认的结构化单题结果或可行动失败状态写回任务。

**Blocked by:** 01 — 识别任务生命周期与安全查询.

**Status:** ready-for-human

- [x] 云托管只传递任务 ID 异步触发指定 Worker，不等待模型完成，也不把图片内容、业务会话或微信凭证传给 Worker。
- [x] Worker 从任务和对象存储引用取得图像，完成单题识别后将题干、公式、题目区域、手写作答和置信度写回 `succeeded` 任务。
- [x] 临时模型故障、超时、429、500、503 可自动重试且最多两次；不可恢复错误和 60 秒未完成任务进入 `failed`，并保存脱敏原因。
- [ ] 云函数调用身份和资源权限遵循最小权限；配置与密钥只来自部署环境，日志不含图片内容、临时 URL、openid、微信 code 或密钥。
- [ ] 集成测试覆盖任务领取、成功写回、可恢复失败重试、不可恢复失败、超时和幂等的外部结果。
